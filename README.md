# Proyecto Urban Routes - Automatización de Pruebas

## Descripción
Este proyecto contiene pruebas automatizadas para la aplicación Urban Routes utilizando Selenium WebDriver y Python. Las pruebas validan el flujo principal de usuario para solicitar un taxi, incluyendo la selección de opciones, ingreso de número de teléfono, método de pago y verificación de la asignación del conductor.

## Tecnologías y herramientas utilizadas
- Python 3
- Selenium WebDriver
- Pytest
- Patrón Page Object Model (POM)
- ChromeDriver

## Casos de prueba automatizados
- Configuración de la ruta
- Selección de la tarifa Comfort
- Ingreso del número de teléfono
- Selección del método de pago
- Solicitud del viaje
- Verificación del modal de asignación del conductor

## Cómo ejecutar las pruebas

1. Instalar dependencias:

Este proyecto utiliza las siguientes dependencias:
- Selenium: herramienta para la automatización de navegadores web
- Pytest: framework para la ejecución de pruebas automatizadas
- ChromeDriver: controlador que permite la comunicación entre Selenium y el navegador Chrome
